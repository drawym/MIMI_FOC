# 2026-11-04 启动策略改造：VF 开环强拖 → 电流闭环

## 背景
I/F 启动（电流闭环+频率开环）抖动严重：电流环带宽 15.9Hz 而基波 14Hz，
增益仅 75%、滞后 41°，磁场畸变导致转子左右晃。
对比：用户之前 VF 开环能平稳转 —— 因为 VF 的磁场由电压直接定义，不依赖反馈。

## 方案
新增独立模块 user/src/vf_start.c + user/inc/vf_start.h（不依赖 currloop0，重新导出不覆盖）
- 0~0.5s 预定位：角度锁 0°，0.8V 直流矢量
- 0.5~10.5s 升频：1Hz→7Hz（0→60rpm），V = 0.8 + 0.05×f
- 10.5s 切闭环：rtDW.is_c3_currloop0=4(RunStage) + 相位交接 + PI 清零

## main.c 改动
- 新增 s_run_phase（STOP/VF/CLOSED）
- foc_step 分两段：VF 阶段调 vf_start_step() 直接写 CCR；闭环阶段调 currloop0_step()
- KEY1 启动进 VF；KEY2 停止并复位
- VF 与 currloop0 的 SVPWM 算法保持一致（Anti-Clark + 中点注入 + duty=0.5-u/Vbus）

## 当前参数
- CurrKp=0.688 / CurrKi=2040（带宽 122Hz，用于闭环段）
- OPEN_RPM_START=10 / OPEN_RPM_END=60（currloop0 自带强拖，现已绕过）
- VF_V_BOOST=0.80V，VF_K_VF=0.05，VF_FREQ 1→7Hz
